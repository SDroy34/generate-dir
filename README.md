# Generate dir

## Descripcion
Es un proyecto para generar directorios para desarrollo de software como MVC o APIs, por el momento solo existen estos dos

## Modo de uso
```sh
generate-dir <nombre-carpeta> [OPCION]

1 | --mvc | -m
	- controllers
	- views
    - css
    - models
 2 | --api | -a
	- routers
	- controllers
	- config
```
En caso de no poner alguna opcion solo genera el directorio.
